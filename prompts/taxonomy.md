# AI 能力前沿分类体系 — Taxonomy

## 9 大领域

1. **能力突破 (`#capability_breakthrough`)** — 模型在某一任务上首次达到/超越人类专家水平、新能力的涌现、评测记录刷新
2. **基准与评测 (`#benchmarks`)** — SWE-bench / ARC-AGI / HLE / GPQA / MMLU 等榜单变化、新基准发布、评测方法论讨论
3. **智能体与自主任务 (`#agents`)** — 长程自主任务（小时级/天级）、计算机操作、浏览器/工具调用、多步推理规划
4. **科学发现 (`#science`)** — AI 在数学、物理、化学、生物医药的发现级成果（新定理、新药、新材料、蛋白质设计）
5. **创造类任务 (`#creative`)** — 视频/音乐/图像/世界模型生成能力的质变、AI 创作进入专业生产流程
6. **机器人与具身 (`#robotics`)** — 人形机器人、物理世界操作、具身智能的自主性进展
7. **效率与成本 (`#efficiency`)** — 开源模型逼近闭源、推理成本下降、蒸馏/量化、小模型能力
8. **安全与对齐 (`#safety`)** — 能力评估、对齐技术、红队发现、欺骗行为研究、评估机构报告
9. **产业与监管 (`#industry`)** — 融资/收购、算力与数据中心、监管政策、人才流动

## 生态群组（跨源交叉验证权重见 quality.yml）
- `lab_official` — 实验室官方（OpenAI / Anthropic / DeepMind / Meta / xAI / 开源前沿）
- `eval_org` — 能力评估机构（Epoch AI / METR / ARC Prize / Scale SEAL / Artificial Analysis / Stanford HAI）
- `academia` — 学术界（arXiv / Nature / Science）
- `benchmark` — 基准聚合（LMSYS / benchlm / Vals AI / llm-stats）
- `intl_media` — 国际媒体（MIT Tech Review / The Verge / TechCrunch）
- `cn_media` — 中文媒体（机器之心 / 量子位）
- `community` — 社区聚合（Hacker News / Reddit / Hugging Face）
- `dev_ecosystem` — 开发者生态（GitHub Trending）
