# AI 能力前沿周报 — ai-frontier-weekly

追踪一个问题的答案：**当前最强的 AI 可以强到什么程度，能实现哪些不可置信的任务？**

每周一自动采集 27 个信息渠道（实验室官方、独立评估机构、学术、基准聚合、媒体、社区），经质量过滤 → 跨生态交叉验证评分 → AI 深度分析，产出结构化周报。

## 信息渠道与权重

完整调研见 [docs/SOURCES.md](docs/SOURCES.md)。核心原则：**多生态交叉验证**——单一来源的事件只给 C 级可信度，2 个以上独立生态交叉验证才给 A/B 级。

| 生态 | 权重 | 说明 |
|---|---|---|
| 实验室官方 | 1.0 | 一手发布，权威但有宣传倾向 |
| 能力评估机构 | 1.0 | 第三方独立验证，最可信 |
| 学术界 | 1.0 | 同行评议 |
| 基准聚合 | 0.9 | 榜单聚合 |
| 国际/中文媒体 | 0.8 | 深度报道 |
| 开发者生态 | 0.8 | 项目热度 |
| 社区聚合 | 0.7 | 噪音较高，降权 |

## 输出

- `output/weekly/YYYY/YYYY-Www.md` — 周报（frontmatter + 深度分析 + Top 20 + 分类整理 + 数据洞察）

## 本地运行

```bash
pip install -r requirements.txt
python run.py --mode weekly          # 生成当期周报
REPORT_WEEK=2026-W37 python run.py --mode weekly   # 补刊指定周
```

LLM 密钥（GEMINI_API_KEY）未配置时自动降级为数据版周报（无 AI 深度分析）。

## 测试

```bash
pytest tests/ -q
```

## 架构

借鉴 8 个 weekly-digest 仓库沉淀的最佳实践：统一评分配置 schema、URL 归一化跨源合并、质量阈值过滤（占位骨架不入库）、去重状态持久化 + 原子写入、ISO 周号（%G-W%V）、表格单元格转义。
